# RevitTools

Набор инструментов для **Autodesk Revit 2027** (работает и в 2025–2026) на базе [pyRevit](https://github.com/pyrevitlabs/pyRevit).
После установки в Revit появляется вкладка **RevitTools** с четырьмя панелями.

| Панель | Кнопка | Что делает |
|---|---|---|
| **Аудит** | Аудит модели | Сводка здоровья модели: предупреждения, модели «по месту», импорт CAD, неиспользуемые семейства, виды без листов, проблемные помещения, размер файла |
| | Предупреждения | Все предупреждения, сгруппированные по тексту, с выделением элементов; экспорт в Excel |
| | Виды без листов | Список видов, не размещённых на листах, и удаление отмеченных |
| **Параметры** | Экспорт параметров | Выгрузка параметров категории (или выделенных элементов) в Excel |
| | Импорт параметров | Загрузка отредактированного файла обратно в модель |
| | Пустые параметры | Проверка заполненности параметров: процент по каждому параметру, выделение пустых |
| **Листы и виды** | Листы из Excel | Создание листов по списку «Номер / Название» с выбранной основной надписью |
| | Пакетное переименование | Виды, шаблоны, листы, уровни, типы, семейства: найти/заменить, префикс, суффикс, нумерация |
| **Помещения** | Отчёт по помещениям | Площади по уровням и отделам, дубли номеров, проблемные помещения; экспорт в Excel |
| | Нумерация помещений | Щёлкайте помещения по порядку — номера присваиваются автоматически |

Все изменения модели выполняются одной транзакцией и отменяются через **Ctrl+Z**.

## Установка

1. **Установите pyRevit 7.0 или новее** — именно с этой версии полностью поддерживается Revit 2027:
   скачайте установщик со страницы [pyRevit Releases](https://github.com/pyrevitlabs/pyRevit/releases)
   (файл `pyRevit_7...._signed.exe`, без `CLI` и `admin` в названии) и запустите.
   Закройте Revit на время установки. Если pyRevit уже стоит старой версии — сначала удалите его.
2. **Скачайте этот репозиторий**: зелёная кнопка **Code → Download ZIP** на GitHub.
   Распакуйте, например, в `C:\RevitTools` — так, чтобы внутри была папка `RevitTools.extension`:
   ```
   C:\RevitTools\
       RevitTools.extension\
       README.md
   ```
3. **Подключите папку в pyRevit**: в Revit откройте вкладку **pyRevit → Settings**,
   в разделе **Custom Extension Directories** нажмите **Add folder**, выберите `C:\RevitTools`,
   затем **Save Settings and Reload**.

   То же самое из командной строки:
   ```
   pyrevit extensions paths add "C:\RevitTools"
   ```
4. Появится вкладка **RevitTools**. Наведите курсор на кнопку, чтобы увидеть подсказку.

### Обновление

Скачайте ZIP заново и замените файлы в `C:\RevitTools`, затем нажмите **pyRevit → Reload**.
Если вы клонировали репозиторий через git — просто `git pull`.

## Работа с Excel

Инструменты пишут и читают **CSV** с разделителем `;` в кодировке UTF-8 — такой файл
открывается в русском Excel двойным щелчком, без мастера импорта.

Чтобы отредактировать параметры в Excel и загрузить обратно:

1. **Экспорт параметров** → выберите категорию и параметры → файл откроется в Excel.
2. Измените значения. **Не трогайте** колонки `ElementId`, `Категория`, `Тип` и заголовки.
3. **Файл → Сохранить как → CSV (разделители — точки с запятой)**.
4. **Импорт параметров** → выберите файл. Инструмент покажет, сколько значений изменится, и попросит подтверждения.

Числа (длины, площади) записываются в единицах проекта, как их показывает Revit.
Для параметров «Да/Нет» можно писать `Да`/`Нет`, `Yes`/`No` или `1`/`0`.

## Структура

```
RevitTools.extension/
├── lib/rt_utils.py            общие функции (CSV, параметры, ElementId)
└── RevitTools.tab/
    ├── Audit.panel/           Аудит
    ├── Parameters.panel/      Параметры
    ├── Sheets.panel/          Листы и виды
    └── Rooms.panel/           Помещения
```

Каждая кнопка — папка `*.pushbutton` со `script.py` (код), `bundle.yaml` (название и подсказка) и `icon.png`.
Скрипты работают на встроенных движках pyRevit — IronPython 2.7 и IronPython 3.4.
